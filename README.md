# E01 · Semaphore Noir 浏览器证明基准

在本次对照中，同样开启跨源隔离，增加线程请求降低了证明耗时：桌面三个深度的中位数耗时比为 **1.69–1.83 倍**，安卓 A 在深度 7 为 **2.16 倍**。桌面录制显示了不同的 Worker 路径；安卓对照只测到了请求设置的效果。这里没有测量内存峰值，也不能反推上游报告当时的运行环境。

**[打开在线演示](https://turbo-coral-oaukmgn.tmp.now/)**，无需安装。首次试跑可选择 **B3、请求 1 线程、深度 7、次数 1**，点击「开始」。

完整实验方法、实测结果和待验证的解释见 [E01 结果文章](docs/e01-results.md)。

## 五分钟复跑

需要 Node.js、npm 和 Chrome；验收使用 Node v24.18.0。首次安装与证明需要网络。无需钱包或密钥。

```bash
npm ci --ignore-scripts
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 `http://127.0.0.1:4173`。确认 **crossOriginIsolated=true**、**SharedArrayBuffer=true**，选择 **B3、请求 1 线程、深度 7、次数 1**，点「开始」。页面自动执行一次预热；两轮都应验证通过并完成清理等待。导出 JSON 后检查 `proofVerified: true`。

同一构建的无隔离对照：另开终端运行 `python3 -m http.server --bind 127.0.0.1 -d dist 8000`，打开 `http://127.0.0.1:8000`，确认隔离和共享内存为 false，再选择 B1。**组别下拉框只标记数据，不切换响应头。**
