# 公开数据脱敏说明

公开 JSON 来自浏览器导出，性能数字、成功状态、组别和预热标记保留。只公开脱敏副本：

- 设备使用 desktop-A（Linux 桌面）与 android-A（安卓手机）。保留浏览器名称及主版本，不公开型号、CPU 型号、完整 User Agent、内核版本、设备标识或内存指纹。
- 不保留绝对时间、时区或原下载文件名。`runOrder` 是同一批的全局次序，`elapsedSeconds` 从该批首条记录开始，取整到秒。跨页的一批使用共同时间原点；不同批次之间不能用它比较日历时间。
- 原始录制和原件留在私有工作区。公开的响应头摘要仅保留可核对隔离的字段；Worker 证据使用匿名摘要。文中的 JSON 哈希对应本仓库脱敏副本。
- 浏览器导出新结果时仍会生成本地绝对时间和 User Agent。拟公开的新数据需要先脱敏。历史数据中的隔离状态、浏览器报告的逻辑处理器数和线程请求保留以便复核。
